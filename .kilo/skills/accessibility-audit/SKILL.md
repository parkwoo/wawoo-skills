# Accessibility Audit

Make core tasks usable without relying on a mouse, colour perception, or one viewport.

1. Identify critical user journeys, page structure, interactive controls, forms, dynamic updates, media, and target accessibility standard if provided.
2. Check semantic landmarks/headings, accessible names, keyboard navigation, focus order and visibility, native controls, error messages, labels, contrast, zoom/reflow, motion, and alternative text.
3. Test representative desktop and narrow viewports. Use automated tools as a supplement, not proof of accessibility.
4. Prioritize blockers to task completion, then high-impact repeated issues. Verify fixes with keyboard and rendered inspection.
5. Report evidence, scope limits, affected users/tasks, remediation, and remaining manual test needs.

Do not claim WCAG conformance or legal compliance unless the required criteria and evidence were explicitly assessed.
