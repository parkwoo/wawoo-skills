# Wayfinder (decision map for huge work)

Drive work that does not fit in one session as a **map of decision tickets** on your issue tracker. Each ticket records a **decision, not a deliverable**.

## Context budget

- Entry: this `SKILL.md` only.
- Full procedure: read [`references/wayfinding-guide.md`](wayfinding-guide.md) only when needed.
- No tracker configured: `setup-matt-pocock-skills`.

## Gates

- **Plan, don't do** (default): the map stops at decisions. Implementation happens outside the map, joining `to-spec` / the main flow.
- Resolve **one** ticket per session (except research).
- Reference tickets by **name**, not only by number.
