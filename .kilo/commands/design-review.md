# Design Review (UI)

> **Entry**: `/design-review` (this command) is the entry. The procedure body is the skill of the same name, **`design-review`** (`.kilo/skills/design-review/SKILL.md`). Skills are model-selected; the `/` entry is fixed to this command.

2. **`design-review`**: visual audit → fix (keep before/after evidence).
3. **`web-design-guidelines`**: check compliance with layout, typography, color, motion, and accessibility standards.
4. **`accessibility-audit`**: keyboard, focus, contrast, semantics.
5. Report: evidence (screenshots/diff), unverified items, risks, next actions. **Do not skip approval gates.**

## Scope

- Consistency between the admin UI (`docs/design/30-ADMIN-DESIGN.md`) and the API spec (`docs/design/12-API-SPEC.md`).
