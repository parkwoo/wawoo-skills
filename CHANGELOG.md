# Changelog

All notable changes to this project are documented here.
Format: [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-25

### Added
- Generic toolkit: 55 skills, 21 agents, 13 workflows.
- MCP capability server (stdio, stdlib only): `capabilities`, `skill_search`, `skill_get`, `workflow_get`, `agent_get`, `memory_recall`, `memory_save`, `evidence_check`.
- Cursor rules and `AGENTS.md` contract.
- `scripts/gen_capabilities.py` (catalog) and `scripts/validate_assets.py` (validation).

### Notes
- Excluded third-party assets with unclear licenses (Marketplace business 3, `fal-gen`).
